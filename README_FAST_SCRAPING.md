# 競艇レース結果高速スクレイピングツール

このリポジトリには、競艇レース結果を高速に収集するための各種スクリプトが含まれています。並列処理を活用して、大量のデータを効率的に取得することができます。

## 主な機能

- 特定日の特定レース場・レース番号のデータを取得
- 1つの開催場の全レースを並列処理で取得
- 複数の開催場のデータを同時に並列処理で取得
- 長期間のデータを高速に取得（2018年～2024年など）
- パフォーマンス測定と並列処理の最適化

## ファイル説明

- `run_fast_scrape.py`: 1つのレースデータを取得してコンソールに表示するシンプルなスクリプト
- `parallel_scrape_test.py`: 並列処理の効果を検証するためのテストスクリプト
- `fast_scrape_test.py`: 複数の日付・レース場のデータを高速に取得して保存するスクリプト

## 必要なパッケージ

```
pandas>=1.0.0
tqdm>=4.45.0
python-dateutil>=2.8.1
```

## 使い方

### 基本的な使い方（1レースのみ）

```bash
python run_fast_scrape.py
```

このスクリプトは指定された1つのレース（デフォルトでは2024-05-06の桐生競艇場第1レース）のデータを取得し、出走表、オッズ、レース結果を表示します。

### 並列処理のパフォーマンステスト

```bash
python parallel_scrape_test.py
```

このスクリプトは並列処理の効果を検証し、以下の情報を表示します：
- シングルスレッドとマルチスレッドの処理時間の比較
- 異なるスレッド数（1, 4, 8）でのパフォーマンス
- 複数開催場を同時に処理する場合の効率
- 最適なスレッド数と大量データ取得の推定時間

### 大量データの高速取得

```bash
python fast_scrape_test.py --start 2024-03-01 --end 2024-04-30 --workers 4
```

このスクリプトは指定した期間（例：2024年3月1日から4月30日まで）の全レースデータを高速に取得し、CSVファイルとして保存します。

#### パラメータ

- `--start`: 開始日（YYYY-MM-DD形式、デフォルト：2024-03-01）
- `--end`: 終了日（YYYY-MM-DD形式、デフォルト：2024-04-30）
- `--workers`: 同時に処理する日付数（デフォルト：4）

## データ保存形式

取得したデータは以下のディレクトリ構造で保存されます：

```
fast_data/
  ├── stadiums/     # 開催場情報
  ├── programs/     # レース出走表
  ├── racers/       # 選手情報
  ├── odds/         # オッズ情報
  └── results/      # レース結果
```

各CSVファイルには日付、開催場番号、レース番号の情報が含まれており、データ分析のために簡単に結合できます。

## パフォーマンスについて

並列処理を活用することで、シングルスレッドに比べて約4〜8倍の高速化が可能です。
最適なパフォーマンスを得るためには、以下の設定が推奨されます：

- 1つの開催場あたり4スレッド
- 同時に処理する開催場数は利用可能なCPUコア数による
- 一度に多くの日付を処理する場合は、処理日数を調整することで負荷を分散

## 注意事項

- スクレイピングのリクエスト頻度が高すぎると、サーバー側から制限される可能性があります
- 長期間のデータ収集は、適切な間隔を空けて実行することをお勧めします
- 収集したデータは研究・分析目的でのみご利用ください
- PHP環境およびbvp-boatrace-scraperライブラリが必要です
